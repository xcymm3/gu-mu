# Android 离线完整 APK

冻结日期：2026-09-03。范围：将现有在线 Android 外壳改为包含全部游戏内容的离线安装包，不重写游戏、不启动旧 Loop。

## 验收标准

- AC1：可重复构建 APK，静态导出的全部页面、脚本、字体、立绘、背景、CG、音频均包含在包内；核对包内文件与本次导出的一致性。
- AC2：应用从包内读取资源，缺失资源不会回退到网络；最终清单无 INTERNET 权限，文件访问与任意外部导航受限。
- AC3：保留应用 ID、HTTPS 存档源、横屏和沉浸式；运行验证首页、开局 CG、正常画面、音频读取和存读档持久化。若无可用 Android 运行环境，必须明确标记运行验证 UNKNOWN，不用浏览器测试冒充真机测试。
- AC4：单元测试、lint、静态导出与 Android lint/构建通过，更新 CI、构建和签名说明，交付带哈希的 APK。
- AC5：保存本次证据、独立重检当前代码，覆盖写入 verdict.json 和 problems.md；仅提交本次相关改动并推送现有远端。

## 边界

- 继续使用 Android 系统 WebView 渲染，但所有游戏内容离线随包提供，不打开在线网站。
- 不生成或提交发布私钥。无发布签名配置时交付明确标注的 debug 签名测试 APK。
- 不卸载现有用户应用、清空真实存档或更改系统安全/虚拟化设置。
- 自动生成的 assets、SDK、构建缓存、APK 留在忽略目录；源码、测试、说明和轻量证据纳入 Git。
