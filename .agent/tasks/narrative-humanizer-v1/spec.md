# 剧情文本精修

## 范围

按 humanizer / humanizer-zh 精修网页玩家可见文本，优先共通线和乔无咎线，落实本次审阅的五类问题。保留仙侠语气、关键线索、人物行动与机关限制。仅调整正文和必要的文案断言，不改变游戏逻辑，不构建或修改 EXE / APK。

## 冻结验收标准

- AC1：替换纪清寒线正文中的“第一幕中”、共通线中的“信息差”及设置页“更静止”的表述。
- AC2：精修共通线环境、动作和选项结果中的修饰堆叠及重复总结；保留旧玉呼应、毒针、四条毒蛊、两种脱险方式、噬魂蛊和幻境线索。
- AC3：精修乔无咎线机关解释；保留主副台分工、互锁范围、传声孔、双门合困、苏莹血钥无伤、旧路绕行、血魔蛊未认主及副印无法提供逃生次序的因果。
- AC4：精修薛逢与赵黎的评判式旁白；保持所有事件索引、人物演出、场景与选项 ID、跳转、条件、效果、战斗、结局正文及存档结构不变。
- AC5：完成当前版本的人工语义复核、非文案结构对比、单元测试、lint、网页 build，并运行分页和路线浏览器回归；不改动原有安装包。记录证据，复核后写入 verdict.json 与 problems.md。
