# 网页存读档证据

范围：只修改网页共享源码、网页测试和文档。原生工程、原生测试与已发布的 EXE / APK 不变，不重新分发安装包。

## 已验证

- `pnpm verify:fast`：109 项 Node 测试、ESLint、TypeScript / Next.js 生产构建 PASS。命令输出见 `../semantic-pagination-v1/raw/web-verification.log`。
- `pnpm test:e2e:run tests/e2e/save-load.spec.ts`：9 项 PASS，45.9 秒。四个视口为 1366×768、844×390、667×375、568×320。包括统一入口、章节信息、覆盖确认 / 取消、重载读档、满六槽旧档兼容、损坏旧档、写入失败、禁用存储、稳定战斗保存及特效期禁用入口。
- 本地生产构建冒烟：以 `http://127.0.0.1:4173` 为目标执行 `pnpm test:e2e:production`，最终构建上 1 项 PASS，7.1 秒。此结果不是对远端线上部署的声明。
- 人工复核：快存 / 快读按钮与 Q / L 动作已移除；旧存储键仅用于兼容读取。章节由当前场景元数据解析，卡片不再隐藏角色或时间；存档界面关闭后按文本锚点继续阅读。

## 修复记录

初轮手机横屏测试发现卡片新增文字后，自动网格行压缩导致按钮被下一行遮挡。已改为 max-content 行高和列表内部滚动，四种尺寸的保存、覆盖、末槽访问和读档复测全部通过。

随后复核发现战败结算存档已具有 `sceneId: "ending"`，旧读档逻辑清空 endingId 后会尝试渲染不存在的普通场景。补丁只对这种终局记录重建结局 ID 和解锁记录，并显示「终章 · 结局」及结局名；普通场景、路线、战斗配置不变。新增 save-boundaries.spec.ts 覆盖实际战败后存入、读取、结局解锁及自动 / 快进暂停，2 项专项复测 PASS。初轮测试误在满真元时查找仅零真元出现的「调息」，已修正测试夹具；没有修改战斗规则来适配测试。

## 边界

存档属于当前浏览器，不跨设备同步；清理站点数据会删除本地存档。旧快速存档只读保留，不迁移覆盖六个常规槽位。无文本锚点的旧版 6 存档从当前场景开头重读，角色与剧情状态保留。选择反馈和战斗结算沿用原有事务边界：未确认选择可重新选择，已完成战斗保存结算后的状态。

## 最终验证与交付

全量网页回归 32 项 PASS（10.9 分钟），覆盖四路线、九结局、30 个角色状态、16 张 CG、布局、存读档与特效。随后添加的终局读档恢复分支仅影响结算存档，不修改这些普通路线；最终源码重新执行 109 项 Node 测试、lint、类型 / 生产构建，以及 20 项分页、存读档、结算边界、自动 / 快进和公开游玩回归，全部 PASS（20 项用时 2.0 分钟）。完整命令输出见 `../semantic-pagination-v1/raw/web-full-regression.log`、`../semantic-pagination-v1/raw/final-targeted-regression.log`。不能将补丁前的 32 项结果误写为补丁后的全量重跑。
