# 完整语义分页证据

## 实现与边界

独立分页模块按作者段落、成对标点及完整句子构成页面，最多两个普通句子。只有单句在空页也无法容纳时才降级到分句或字素。共享渲染与隐藏测量节点使用相同的字体和强调词样式；ResizeObserver、字体加载和样式变化触发重新排版。阅读位置保存原文锚点，窗口变化不会依赖旧的屏幕页码。

正常支持的桌面与横屏手机不得发生正文裁切；极小到容不下一字素的窗口无法同时保证不滚动与完整显示，算法必须保留原文。未改写剧本。
