# 完整语意优先的剧情分页

冻结日期：2026-09-03。范围：统一剧情、选项结果和战斗结算的分页，不改写剧情内容或更换技术栈。

- AC1：段落、说话人、演出事件保持独立；一页最多两个完整句子，宁可留白。正常句子不得因字数阈值在逗号处分成两页；句末连续标点与闭引号/括号保持相连。
- AC2：根据当前对话框、字体与强调文字的真实排版判断容量。只有单个完整句子在空页也放不下时，才按分号、逗号等降级；极长无标点内容有保底，不丢字、不重字、不拆 Unicode 字素，不产生孤立标点页。
- AC3：窗口/字体变化后重排，阅读位置按事件与文本偏移保持；新手动/快速存档保存位置锚点。已有无锚点存档保留游戏状态，从当前场景开头安全重读。
- AC4：单元测试、lint、类型/生产构建，以及桌面/手机浏览器的分页容量、阅读推进、历史/快进/存读档、选项/战斗回归通过；保留截图与命令证据。
- AC5：当前代码独立复核，保存 evidence.md/json、覆盖 problems.md/verdict.json，仅提交并推送本任务文件。

边界：不启动 Loop，不修改真实玩家存档；使用专用测试浏览器数据。极小到连一个字素都放不下的窗口不可能同时满足完整显示与不滚动，需明确标记异常，不能丢弃文字。本次先交付并验证共享源码；已有 EXE/APK 不会自动更新，是否重新分发安装包以最终交付说明为准。
