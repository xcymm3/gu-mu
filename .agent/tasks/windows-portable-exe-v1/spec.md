# Windows 便携版 EXE

任务 ID：`windows-portable-exe-v1`

## 冻结范围

基于现有 Next.js 静态导出，添加 Windows x64 离线桌面外壳和可重复执行的打包命令，生成免安装的单文件 EXE。不更改剧情、美术或游戏规则，不启动旧 Loop，不发布 GitHub Release；生成物留在被忽略的 dist 目录，源码和验证记录提交到现有远端。

## 验收标准

- AC1：存在一条可重复执行的 Windows 便携版构建命令，生成包含 Chromium 运行时及本地游戏资源的 x64 EXE，无需目标机器安装 Node.js 或启动 Web 服务。
- AC2：桌面版在固定本地来源加载资源，无需游戏站点或其他远端服务；首页、开场 CG 及章节标题、正常阅读、存读档与本地音频可用。
- AC3：EXE 同目录的 `血蛊引-data` 保存设置和存档；关闭再启动可读取，移动 EXE 及数据目录可继续读取。不可写目录给出明确错误，不静默丢弃存档。
- AC4：渲染器启用沙箱和上下文隔离、关闭 Node 集成，禁止外部导航和窗口；静态资源访问限制在导出目录内。对应自动化测试通过。
- AC5：项目原有快速门禁和新增桌面测试通过；对实际 portable EXE 做启动及保存/重启验证，记录产物大小和 SHA-256，并补充使用、备份、构建与未签名提示文档。

## 验证方法

单元测试覆盖资源寻址和路径边界；现有 test/lint/build 回归；桌面运行验证检查真实渲染及跨启动持久化。所有测试使用独立临时数据，不改动玩家已有存档。复核当前代码和最新命令结果后写入 evidence.md/evidence.json、verdict.json 和 problems.md。
