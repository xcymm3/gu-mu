# 《血蛊醒》发布检查清单

当前候选版本：`0.2.0-rc.1`  
封板日期：2026-08-24  
发布基线：Vercel 静态导出，桌面端优先，手机端保留完整降级体验。

## 自动质量门

每次发布前必须在仓库根目录依次通过：

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm lint
pnpm build
```

`pnpm test` 同时检查：

- 固定五幕节点合同与全部场景跳转；
- 赵黎、纪清寒、薛逢、苏莹献祭、苏莹墓主、乔无咎暗线六条基准路径；
- 九个结局的解析结果与三个身份的图鉴可达性；
- 六个手动存档槽、快速存档、战斗结算待确认状态和损坏存档回退；
- 战斗平衡设计，其中游方蛊医不能击败苏衍属于预期规则；
- 所有登记图片存在，单文件不超过 600 KB，总视觉资源不超过 4.5 MB。

GitHub Actions 的 `Quality Gate` 会在推送到 `master` 和拉取请求时重复执行上述四项命令。

## 人工验收矩阵

桌面端必须覆盖：

- 1280×720
- 1366×768
- 1440×900
- 1920×1080

手机降级必须覆盖：

- 375×812
- 390×844

每个尺寸检查主菜单、身份选择、正文、三选项、蛊斗、历史、设置、存档菜单与结局页。页面本身不得出现横向或纵向滚动；仅历史列表、设置内容、存档列表及明确允许的长内容区域可内部滚动。对话、选项、状态栏与快捷栏不能相互遮挡。

## 输入与无障碍

- 仅用键盘完成主菜单、身份选择、正文推进、选项和菜单操作；
- `Enter / Space / A / B / H / Q / L / Esc` 与界面标注一致；
- 所有按钮在 `Tab` 聚焦时显示清晰焦点环；
- 打开历史、游戏菜单或蛊斗帮助后，焦点首先进入关闭按钮；
- 检查正文、选项和状态文本在亮色、暗色两种主题下的对比度；
- 开启系统“减少动态”或游戏内“减少动态”后，不出现文字淡入、背景淡入、立绘过渡、闪白、震动和等待脉冲。

## 资源与失败回退

- 首屏墓门背景使用压缩 WebP；
- 关键首屏资源由 Next.js 优先加载，其余登记图片在浏览器空闲期预载；
- 图片加载失败时，舞台继续显示安全渐变背景与“场景暂缺”，立绘回退为带人物名的剪影；
- 第二幕甬道、关键战斗和全部结局舞台均使用登记的 WebP，不再使用开发期 CSS 占位背景；
- 背景音乐、环境声与界面／战斗音效使用仓库内原创 WAV；音频加载、解码或播放失败时自动使用轻量合成回退，不阻止阅读；
- 单张视觉资源不超过 600 KB、登记视觉资源总体不超过 4.5 MB；单个音频不超过 600 KB、登记音频总体不超过 2.6 MB。

## 发布与回滚

1. 确认工作区干净并记录发布提交哈希；
2. 推送 `master`，等待 GitHub `Quality Gate` 与 Vercel Production 部署均成功；
3. 从公网域名执行一次主菜单、开始游戏、存档和读取冒烟测试；
4. 若出现阻断问题，在 Vercel 重新部署上一个稳定提交 `edc23a1`，或对本次发布提交执行 `git revert <发布提交哈希>` 后推送；
5. 不使用 `reset --hard` 回滚线上版本，确保发布历史可追溯。

## 本候选版已知边界

- 立绘与背景仍属于第一版正式资源，部分表情复用同一张基础立绘；
- 当前音频为原创合成母带，尚未经过真人乐器与 Foley 录音混音；
- 本候选版只做质量封板，不新增剧情，也不修改战斗数值。
