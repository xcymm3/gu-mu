# 《血蛊引》资源来源与授权记录

## 视觉资源

- `public/backgrounds/*.webp` 与 `public/characters/*.webp` 均为本项目在 Codex 上下文中使用内置 imagegen 生成或编辑的项目资产，没有引入商业游戏截图、网络下载图片或第三方角色素材。
- 可复现提示词与透明背景编辑要求记录在 `docs/art-prompts.md`。原始生成图只作为制作中间件，运行时统一使用仓库内压缩后的 WebP。
- `public/characters/ji-qinghan-placeholder.webp` 是早期生成稿，仅为保留历史资源，不再被运行时代码、资源清单或预加载器引用；主菜单与剧情统一使用 `ji-qinghan-v1.webp`。
- 生成资源仅用于本项目构建与发布；若将单个素材移作项目外用途，应重新核对所使用图像生成服务当时的条款。

## 音频资源

- `public/audio/*.wav` 由 `scripts/generate-audio-assets.mjs` 在本仓库内确定性生成，不包含采样包、录音、乐曲片段或其他第三方声音。
- 三条配乐、三条环境声与七条界面／战斗音效采用原创振荡器、周期频谱层和包络组合；脚本的固定种子保证重新生成结果一致。
- 音频文件可随本项目构建与发布。运行时 Web Audio 合成仅作为静态文件加载或解码失败时的功能回退，不是默认声音来源。

## 发布预算

- 登记视觉资源：单文件不超过 600 KB，总计不超过 4.5 MB。
- 登记音频资源：单文件不超过 600 KB，总计不超过 2.6 MB。
- 预算由 `tests/release.test.ts` 读取实际文件并强制验证，未登记或缺失的运行时资源不能通过发布门禁。
