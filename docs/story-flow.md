## 六、四条同行线

### A · 赵黎线（猛虎同行，伺机反制）

赵黎以压倒性蛊力开路，冷漠看同伴一个个死于祭阵、傀儡与机关。你暗记血魔蛊畏寒的冰寒秘术。终局击败赵黎夺血魔蛊，再战乔无咎——用血魔蛊则成魔（demon），克制震碎则独活（lone）。

关键 TAG：`冰寒蛊简`。

### B · 纪清寒线（并肩信任，生死相依）

你与纪清寒互为后背，替她挡拳得生命强化。苏莹死于祭阵。终局你选择炸毁祭阵，二人修为尽废，归隐山野（severed）。

关键奖励：`routeTrial` 生命上限 +4。

### C · 薛逢线（圆滑算计，识破反制）

薛逢沦为乔无咎暗线，假喊报方位引蛊矢袭你，被你识破。你留下活蛊线逆向印记。终局反制控制室，乔无咎反噬、临死捏碎薛逢心脉（tyrant）。

关键 TAG：`活蛊线印记`。

### D · 苏莹线（血脉真相，守护抉择）

苏莹与墓主苏衍同脉。傀儡袭来时，若三线索（旧玉发烫 + 生门低语 + 活符低语）齐备则苏莹存活，否则苏莹死（死前告知"我的血能开门"）。

- 苏莹死 → 以身入池，与血魔蛊共生（sacrifice）。
- 苏莹存活 → 苏衍复苏、夺回血魔蛊，五人联手斩苏衍（masterBattle）→ true。

## 七、战斗与敌人属性

### 铜皮傀儡（第二幕·节点5，热身）

- **HP 12**｜攻击循环 `2 → 3 → 5`
- 胜/败均进 fog，**无奖励**。

### 血傀儡（第四幕·节点1，守门）

- **HP 20**｜攻击循环 `4 → 6 → 8`
- 胜 → **真元上限 +4**；败 → 无奖励（赵黎出手，不死）。

### 赵黎（第四幕·赵黎线决战）

- **HP 22**｜攻击循环递增（9 回合）：`4 → 6 → 镜 → 4 → 7 → 镜 → 4 → 8 → 镜`（镜 = 无敌 + 反弹）
- 胜 → 获血魔蛊，进 qiaoReveal；败 → deathByZhao。

### 乔无咎（第四幕·赵黎线胜后）

- **HP 24**｜攻击循环 `3(抽1真元) → 6(抽1) → 9(抽2)`（**每击抽你真元**）
- 胜 → demon（用血魔蛊）/ lone（不用）；败 → death。

### 苏衍（第四幕·苏莹存活线）

- **HP 28**｜攻击循环 `4 → 6 → 9 → 回5 → 血魔蛊(6伤6回)`
- 胜 → true；败 → deathByMaster。

## 附：已知设计缺口

**蛊医走苏莹线（苏衍战）无法通关**——即使拿满强化（血刃蛊 + 真元4 + 生命4）也过不了苏衍（HP28 + 每循环回 11）。此为已确认保留的设计：蛊医无法达成真结局 `血脉归位`。
