## 状态影响表

| 状态类别 | 来源 | 当前作用 |
|---|---|---|
| 线索 | 察看血锁、井底玉牌 | 与沈青萝的关系共同决定“两人出墓” |
| 人物关系 | 与沈青萝、赵黎、贾贵、乔无咎的互动 | 不在界面显示；保留给剧情与后续分支使用 |
| 蛊与旗标 | 血甲蛊、血流蛊、赵黎夺蛊 | 血甲蛊强化防御或最终血卫；血流蛊开启血卫战；赵黎夺蛊决定“命丧蛊墓” |
| 伤势与时间 | 战败、冒险选择 | 影响后续生存与“困墓之人” |

## 维护约定

新增或删除一个剧情节点时，同时更新：

1. stories/gu-tomb.ink 或 lib/gu-tomb/game.ts：文本、选择和跳转；
2. lib/gu-tomb/game.ts：选择后果、战斗配置与结局判定；
3. 本图：节点、战斗和结局连线；
4. tests/game.test.ts：至少覆盖新增分支的关键状态。
