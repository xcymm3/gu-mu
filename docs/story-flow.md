# 《血蛊引》当前剧情结构

> 本文只记录当前代码中能够实际游玩的剧情。场景接线以 `lib/xue-gu-yin/story/routes/` 为准，节点合同位于 `routes/contract.ts`，状态与战斗以 `game.ts`、`combat.ts` 为准。个人线的二选一只替换当场回应，不改数值、旗标、后续节点和结局。

## 一、主角与隐藏人格

| 身份 | 生命 | 真元 | 攻击 | 神识 | 专属蛊 |
| --- | ---: | ---: | ---: | --- | --- |
| 游方蛊医 | 14 | 12 | 3 | 中 | 回春蛊 |
| 流浪剑修 | 15 | 10 | 4 | 中 | 剑鸣蛊 |
| 世家之子 | 12 | 10 | 3 | 高 | 惑心蛊 |

三种身份均为无姓名男性，正文统一使用“你”。身份影响战斗，不直接决定路线；游方蛊医按当前平衡无法击败苏衍，不能解锁苏莹线真结局。

第一、二幕选择会塑造不直接显示的隐藏人格：

| 人格 | 行为倾向 | 锁定路线 | 固定胜利结局 |
| --- | --- | --- | --- |
| 力量 `power` | 接近强者、争夺机缘 | 赵黎线 `zhao` | 夺蛊成魔 |
| 关怀 `compassion` | 救人、承担代价 | 纪清寒线 `ji` | 断脉相守 |
| 洞察 `insight` | 追索古文、血脉与墓主 | 苏莹线 `su` | 血脉归位 |
| 权谋 `scheme` | 观察弱点、交换筹码、争取机关权限 | 乔无咎线 `traitor` | 副印止步 |

`fog` 是唯一锁线点。单一人格最高时只显示对应行动；多人格并列时显示并列行动供最后确认。路线锁定后，选择不再改变人格、路线或主结局。

## 二、五幕合同与总流程

| 幕 | 节点数 | 职责 |
| --- | ---: | --- |
| 第一幕 | 3 | 墓门集结，以三次现场行动初步塑造人格 |
| 第二幕 | 7 | 继续塑造人格、取得蛊虫、完成热身战并在大雾锁线 |
| 第三幕 | 每线 4 | 人物路线展开；每线有一个对话二选一 |
| 第四幕 | 每线 6 | 独立高潮；每线再有一个对话二选一 |
| 第五幕 | 每线 2 | 战后收束与路线固定结局 |

```text
gate → rainMark → bloodThreshold
  → swarm → shadow → chamber → illusion → stoneBridge → puppets【战斗】→ fog【锁线】
      ├─ 力量 → 赵黎线：12 节点 / 2 次对话二选一 / 3 场战斗 → 夺蛊成魔
      ├─ 关怀 → 纪清寒线：12 节点 / 2 次对话二选一 / 2 场战斗 → 断脉相守
      ├─ 洞察 → 苏莹线：12 节点 / 2 次对话二选一 / 2 场战斗 → 血脉归位
      └─ 权谋 → 乔无咎线：12 节点 / 2 次对话二选一 / 无战斗 → 副印止步
```

第三幕起四条路线完全分开，不再拥有公共高潮。每条线固定放置两个二选一节点，分别位于第三幕和第四幕。两个选项表达不同态度，也会触发不同回应，但始终汇入同一个后续节点；赵黎、纪清寒、苏莹线的战斗失败会提前进入独立死亡结局。

## 三、共通线

锁线前固定有 8 次态度选择：7 个二选一节点，加上机关暗室的 1 个三选一节点，共 17 个可选行动。它们不是平均铺开的四项人格问卷，而是根据当下场景只给出自然成立的做法。

| 人格 | 可选行动数 |
| --- | ---: |
| 关怀 | 5 |
| 力量 | 5 |
| 权谋 | 4 |
| 洞察 | 3 |

### 第一幕

1. `gate` 夜雨墓门【力量／洞察】：落后赵黎半步暗中观察其血纹蛊，或静待墓门蛊纹下一次微光闪烁。
2. `rainMark` 雨洗蛊纹【关怀／权谋】：喊住薛逢并指明蛊纹下的剧毒针孔，或佯装不知，借他踩中机关探明禁制的威力与范围。选择提醒会记录“纪清寒回护”；选择旁观时机关发作，由纪清寒挡下毒针。
3. `bloodThreshold` 血门将合【力量／关怀】：运转真元，以本命蛊托住石阶尽头坠落的石闸；或放弃硬撑，先替纪清寒震断缠腕毒蛊，由她以剑锋卡住制动齿轮片刻。

### 第二幕

1. `swarm` 甬道蛊潮【洞察／权谋】：一边抵挡噬魂蛊、一边暗中观察它们为何避开苏莹，或悄然借赵黎的血火避开虫潮、隐藏自身手段。
2. `shadow` 血影示警【力量／权谋】：按住旧玉，含蓄表明入墓后的机缘各凭本事，或顺着残禁的说法带过血影、趁机藏好旧玉。
3. `chamber` 机关暗室【力量／关怀／洞察】：直接取血刃蛊、先取甲纹蛊卵替众人试险，或“让苏莹先选”。后两项分别固定取得血甲蛊、随机取得血甲蛊或血刃蛊；让苏莹先选还会获得洞察 +1。
4. `illusion` 迷魂阵【关怀／权谋】：主角在青梅竹马的幻境中握住一只手，醒来才发现握着的是纪清寒。乔无咎最先恢复并着手关闭阵眼；主角可以先提醒纪清寒稳住心神，或示意她佯装未醒，趁机观察其余几人在幻境中的失态。
5. `stoneBridge` 断梁墓沟【力量／关怀】：狭窄石梁受力后会沿转轴翻入深沟。主角可以抢在石梁翻转前抵达对岸、击碎机关蛊核，也可以与纪清寒分守两端锁槽，接应所有人通过后再最后撤离。
6. `puppets` 铜皮傀儡：石门落下后，主角独自迎战一具守墓傀儡。生命 12，伤害循环 2、3、5；胜利摧毁胸前蛊核并进入大雾，战败则显示专属落败文本，再进入“命丧守墓傀儡”结局。若此前提醒众人避开墓门机关，纪清寒会在石门闭合前以剑意回护，使生命上限 +4，但不恢复当前生命。
7. `fog` 大雾迷踪：根据最高人格显示锁线行动，进入四条独立路线；也可留在原地等待机关停歇，因耗尽时辰进入“困于蛊墓”超时兜底结局。

血刃蛊令基础攻击伤害翻倍；血甲蛊替换甲衣蛊并免疫当前回合全部伤害。二者是血傀儡战的重要前置强化。

## 四、赵黎线：力量最终吃掉追逐力量的人

### 第三幕

1. `zhaoTrail` 逐血而行：你在坠落机关中追上赵黎，沿血纹蛊留下的血光与他同行。
2. `zhaoLesson` 强者之法：赵黎以残尸血气和自身精血开启血封；寒骨崩碎后，你固定取得记载血道弱点的“冰寒蛊简”。
3. `zhaoPrice` 力量的价钱【对话二选一】：薛逢被困在支道，你与赵黎均不折返。你可以判断连机关都过不了的人不值得冒险，也可以记下位置，等薛逢自行脱困后再取他掌握的乔家路线。
4. `zhaoThreshold` 同盟尽头：两人各自压住一侧阵枢打开血门，默认血魔蛊现世后临时同盟结束。

### 第四幕

1. `zhaoBloodGate` 血祭真相：祭殿的五道阵纹持续向蛊茧供血，乔无咎承认同行者本就是开门与养蛊的祭材；赵黎则察觉唤醒血魔蛊仍缺最后一股血气。
2. `zhaoBloodGuard` 资格之战【战斗】：你独自迎战守门血傀儡，赵黎留在阵线外等待血核暴露；战败进入“命丧守墓傀儡”。
3. `zhaoAwakening` 五转蛊醒【对话二选一】：赵黎以血纹蛊抽取破裂血核中的存血，再倒入沿途收集的血液，补足蛊茧所需。你可以点破他借你破开血核，也可以承认自己同样一直在等蛊醒后的争夺；两种回应都会进入 `zhaoDuel`。
4. `zhaoDuel`【战斗】：与拥有反弹血幕的赵黎决战；战败进入“血蛊反噬”。
5. `zhaoClaim`：击败赵黎并固定炼化血魔蛊，替换原攻击蛊。
6. `zhaoQiaoDuel` 牵机尽断【战斗】：以血魔蛊对抗乔无咎的牵机丝、侧门傀儡与控制台机关；战败进入“命丧牵机阵”。

### 第五幕

`zhaoFall` 中你主动撤去蛊窍禁制，任血魔蛊沿五道祭线抽取墓中所有活人；阵力随之耗尽。`zhaoEpilogue` 描写你在清晨独自出墓，并在此后数年以血魔蛊夺取对手气血，固定解锁“夺蛊成魔”。

## 五、纪清寒线：伸出的手要握到最后

### 第三幕

1. `jiTrail` 断剑回声：你在雾中与纪清寒重新会合并固定接受包扎，生命上限 +4，当前生命不变。
2. `jiPromise` 未尽之约【对话二选一】：她入墓是为至亲寻找续命蛊材，却不愿把邪蛊带回世间。两个选项分别回应她的亲人和她选择承担的代价，最终都决定继续同行。
3. `jiBurden` 不可松手：两人放弃已经开启的近路，折返把苏莹从合拢的石门与傀儡前救出。
4. `jiThreshold` 共赴血门：你与纪清寒同时截断血门两侧锁纹，苏莹从后方报出开门时机。

### 第四幕

1. `jiBloodGate` 先救活人：进入祭殿后先截断拖向赵黎与薛逢的祭线。
2. `jiBloodGuard` 血池救援【战斗】：纪清寒压住两道祭线，你迎战挡住池沿的血傀儡；战败进入“命丧守墓傀儡”。
3. `jiRescue` 一个不落：你踏下池沿截断最后一道祭线，与纪清寒合力救回苏莹。
4. `jiArrayTruth` 线后之人【对话二选一】：断线回缩后指向墙内控制线，确认乔无咎在远处操纵机关。两个选项表达不同的临别安排，但都会由纪清寒留守伤者、你进入控制室。
5. `jiQiaoDuel` 斩断执线者【战斗】：迎战乔无咎及其牵机机关；战败进入“命丧牵机阵”。
6. `jiDestroyGu` 破蛊断脉：你与纪清寒同时逆转本命蛊息，自毁修为并借阵眼对冲，在血魔蛊完成蜕变前将其摧毁。

### 第五幕

`jiAftermath` 让五名幸存者沿检修甬道离墓；`jiEpilogue` 描写你与纪清寒失去修为后共同经营山野药铺的生活，固定解锁“断脉相守”。

## 六、苏莹线：血脉不是命令

### 第三幕

1. `suTrail` 雾中古文【对话二选一】：沿雾中古文找到苏莹，确认她认识苏氏旧印。你可以直接追问她与苏氏的关系，也可以先陪她看完阵盘古文。
2. `suInscription` 未死之人：旧玉照亮断碑残文，墓图与铭文共同表明墓主苏衍可能借后人血脉返生。
3. `suLineage` 血脉之钥：旧玉嵌入辅槽分担阵枢牵引，苏莹依墓图解除三重石环；两人均未受伤，并固定记录“苏莹存活”和“苏氏血钥”。
4. `suThreshold` 血门认主：旧玉稳住旁枢，苏莹亲手开启承认其血脉、却无法强制其“奉主”的石门。

### 第四幕

1. `suBloodGate` 祖阵深处：绕过蛊茧，沿未被后人改动的苏氏旧纹追查黑棺与祖阵。
2. `suBloodGuard` 守墓之物【战斗】：迎战被后来阵线灌入血气、强行唤醒的苏氏守墓血傀儡；战败进入“命丧守墓傀儡”。
3. `suCoffin` 空棺遗文：旧玉照出反刻底纹，证实黑棺只是苏衍舍弃旧躯、转运血气的一环，后人很可能只是返生阵所需的血食。
4. `suMasterTruth` 血脉拒命【对话二选一】：苏衍要求苏莹回到阵位。两个选项分别否认旧债或强调她自己的名字；苏莹随后逆转血钥印记，使强制阵光自行崩断，而非以受伤或自残破局。
5. `suMasterDuel`【战斗】：苏衍生命 28，兼具回血与吸血；战败进入“命丧墓主”。游方蛊医按设计无法获胜。
6. `suCollapse` 祖阵崩塌：苏衍败亡后，你与苏莹以棺侧总枢石钥依次开启五条生路，反向绷断乔无咎的牵机丝，并让残余蛊茧失去供血。

### 第五幕

`suAftermath` 让五名入墓者重新汇合并沿旧纹离开内墓；`suEpilogue` 中苏莹保留自己的姓氏与来历，却不再接受血脉替她作决定，并与你约定继续查清墓图余下标记，固定解锁“血脉归位”。

## 七、乔无咎线：借来的权限通不到归途

### 第三幕

1. `traitorTrail` 雾中识路【对话二选一】：你从薛逢避开翻板、暂缓机关和辨认伪墙的动作中确认他熟悉外围墓道。你可以逐步追问落脚依据，也可以故意报错开门次序，逼他出言纠正；两种做法都会打开检修暗门。
2. `traitorKnife` 无用之人：你识破薛逢试图踩实警线的动作，以本命蛊灭口并夺得只能控制外围机关的牵机副印。
3. `traitorBargain` 第二双手：控制室主台掌管祭阵内门，副台掌管外围岔路；乔无咎缺少操作副台的人，你也需要主台放行，于是接手副印成为临时合作者。
4. `traitorOath` 牵机互锁：双方不立血誓，而是以主副台卡齿互锁限制彼此；当前机关运转完成以前，谁都无法单独带印离开。

### 第四幕

1. `traitorControlRoom` 三线归阵：副台只能以牵机丝的轻重和刻度判断三人的粗略位置。你调整右侧岔路，再借传声孔让谨慎试探的纪清寒转向回声廊。
2. `traitorTrapJi` 双门合困：待纪清寒越过中段，你与乔无咎同步关闭外门和内门，将她困入隔室；她没有受伤，长剑也没有折断。
3. `traitorSacrificeSu` 血钥献祭：苏莹触发苏氏旧阵后，你关闭来路，乔无咎将后来加设的祭阵细线接入祖阵回应；苏莹被石环限制，但没有流血或受伤，并开始寻找断开新线的方法。
4. `traitorQiaoTriumph` 认主之前【对话二选一】：互锁解除后，你可以顺从地询问自己该守哪道外槽，也可以借检查卡齿逐道核对线槽。两种方式都会确认乔无咎只让你控制外环，主印仍独占认主接口。
5. `traitorZhaoArrives` 局外之人：赵黎循血气痕迹从苏氏旧维护道进入血池，绕开主副台记录的已知门路。
6. `traitorBloodTaken` 血蛊易主：赵黎以既有血纹蛊作为临时导血媒介，破坏内环供血节奏；乔无咎受创却未当场死亡，你放弃替他扶正主印，经维护夹道撤回外围。

### 第五幕

`traitorDiscarded` 中，副印只能开启外围门位；你因缺少总枢的门位次序误入没有内侧机关的缓冲室。`traitorDeath` 中你主动催动本命蛊尝试从开启的门缝突围，却被赵黎以血纹蛊和返流阵线困住、抽走气血，固定解锁“副印止步”。此线没有临时洗白、突然反杀或凭副印直接出墓的分支。

## 八、战斗、结局与维护规则

| 战斗 | 生命 | 失败结局 |
| --- | ---: | --- |
| 路线血傀儡 | 20 | 命丧守墓傀儡 |
| 赵黎 | 22 | 血蛊反噬 |
| 乔无咎 | 24 | 命丧牵机阵 |
| 苏衍 | 28 | 命丧墓主 |

所有高潮战都在各自 `BattleConfig` 中显式填写 `defeatEnding`，不再由 `game.ts` 根据敌人名字猜测结局。主要固定结局为“夺蛊成魔”“断脉相守”“血脉归位”“副印止步”；“困于蛊墓”仅作异常或超时兜底。

每场战斗结束后，当前生命统一恢复至生命上限，胜败均执行这一结算。剧情选择和战前成长不再提供当前生命恢复；纪清寒在傀儡战前的剑意回护与她在个人线中的包扎只提高生命上限。游方蛊医的回春蛊、血魔蛊吸血等战斗内技能仍保留，因为它们属于回合策略而非场外恢复项。

- 四条路线的第三、四、五幕不得互相跳转，也不得重建公共高潮。
- `routes/contract.ts` 固定每线 4／6／2 个节点；修改结构必须同步更新合同和测试。
- 每条个人线固定保留两个二选一节点，一个在第三幕，一个在第四幕。两个选项必须拥有不同回应、相同 `next`，且不得附加 `effect`。
- 路线内选择只推进剧情与表达人格；除战败外，不得产生第二个主结局。
- 新战斗必须显式声明胜败去向和死亡结局，不得在 `game.ts` 按敌人名称硬编码。
- 当前存档版本为 6。旧版存档的共通线节点接线已经失效，必须拒绝读取。
