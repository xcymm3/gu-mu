# 《血蛊引》当前剧情结构

> 本文只记录当前代码中能够实际游玩的剧情。场景接线以 `lib/xue-gu-yin/story/routes/` 为准，节点合同位于 `routes/contract.ts`，状态与战斗以 `game.ts`、`combat.ts` 为准。个人线的二选一只替换当场回应，不改数值、旗标、后续节点和结局。

## 一、主角与隐藏人格

| 身份 | 生命 | 真元 | 攻击 | 神识 | 专属蛊 |
| --- | ---: | ---: | ---: | --- | --- |
| 游方蛊医 | 14 | 12 | 3 | 中 | 回春蛊 |
| 流浪剑修 | 15 | 10 | 4 | 中 | 剑鸣蛊 |
| 世家之子 | 12 | 10 | 3 | 高 | 惑心蛊 |

三种身份均为无姓名男性，正文统一使用“你”。身份影响战斗，不直接决定路线；游方蛊医按当前平衡无法击败苏衍，不能解锁苏莹线真结局。

第一、二幕选择会塑造不直接显示的隐藏人格：

| 人格 | 行为倾向 | 锁定路线 | 固定胜利结局 |
| --- | --- | --- | --- |
| 力量 `power` | 接近强者、争夺机缘 | 赵黎线 `zhao` | 夺蛊成魔 |
| 关怀 `compassion` | 救人、承担代价 | 纪清寒线 `ji` | 破蛊断脉 |
| 洞察 `insight` | 追索古文、血脉与墓主 | 苏莹线 `su` | 血脉归位 |
| 权谋 `scheme` | 利用棋子、主动加入阴谋 | 乔无咎线 `traitor` | 叛徒 |

`fog` 是唯一锁线点。单一人格最高时只显示对应行动；多人格并列时显示并列行动供最后确认。路线锁定后，选择不再改变人格、路线或主结局。

## 二、五幕合同与总流程

| 幕 | 节点数 | 职责 |
| --- | ---: | --- |
| 第一幕 | 3 | 墓门集结，以三次现场行动初步塑造人格 |
| 第二幕 | 7 | 继续塑造人格、取得蛊虫、完成热身战并在大雾锁线 |
| 第三幕 | 每线 4 | 人物路线展开；每线有一个对话二选一 |
| 第四幕 | 每线 6 | 独立高潮；每线再有一个对话二选一 |
| 第五幕 | 每线 2 | 战后收束与路线固定结局 |

```text
gate → rainMark → bloodThreshold
  → swarm → shadow → chamber → illusion → stoneBridge → puppets【战斗】→ fog【锁线】
      ├─ 力量 → 赵黎线：12 节点 / 2 次对话二选一 / 3 场战斗 → 夺蛊成魔
      ├─ 关怀 → 纪清寒线：12 节点 / 2 次对话二选一 / 2 场战斗 → 破蛊断脉
      ├─ 洞察 → 苏莹线：12 节点 / 2 次对话二选一 / 2 场战斗 → 血脉归位
      └─ 权谋 → 乔无咎线：12 节点 / 2 次对话二选一 / 无战斗 → 叛徒
```

第三幕起四条路线完全分开，不再拥有公共高潮。每条线固定放置两个二选一节点，分别位于第三幕和第四幕。两个选项表达不同态度，也会触发不同回应，但始终汇入同一个后续节点；赵黎、纪清寒、苏莹线的战斗失败会提前进入独立死亡结局。

## 三、共通线

锁线前固定有 8 次态度选择：7 个二选一节点，加上机关暗室的 1 个三选一节点，共 17 个可选行动。它们不是平均铺开的四项人格问卷，而是根据当下场景只给出自然成立的做法。

| 人格 | 可选行动数 |
| --- | ---: |
| 关怀 | 5 |
| 力量 | 5 |
| 权谋 | 4 |
| 洞察 | 3 |

### 第一幕

1. `gate` 夜雨墓门【力量／洞察】：靠近赵黎看清他收蛊的手法，或等待墓门蛊纹再次回应旧玉。
2. `rainMark` 雨洗蛊纹【关怀／权谋】：把温脉符递给纪清寒，或借扶薛逢试出乔无咎刻意避开的蛊纹。前者记录“纪清寒回护”，后者记录“识破棋局”。
3. `bloodThreshold` 血门将合【力量／关怀】：正面撑住闭合石门，或回身替纪清寒斩断缠住剑腕的蛊虫。

### 第二幕

1. `swarm` 甬道蛊潮【洞察／权谋】：观察噬魂蛊为何避开苏莹，或让薛逢替自己试出虫潮规律。
2. `shadow` 血影示警【力量／权谋】：正面回应赵黎的夺玉威胁，或故意淡化血影、观察乔无咎的反应。
3. `chamber` 机关暗室【力量／关怀／洞察】：直接取血刃蛊、先取甲纹蛊卵替众人试险，或“让苏莹先选”。后两项分别固定取得血甲蛊、随机取得血甲蛊或血刃蛊；让苏莹先选还会获得洞察 +1。
4. `illusion` 迷魂阵【关怀／权谋】：先扶住纪清寒，或假装仍在幻境中等待乔无咎与薛逢露出破绽。
5. `stoneBridge` 断梁墓沟【力量／关怀】：抢先过梁破坏对岸机关，或留下来与纪清寒一同稳住石梁。
6. `puppets` 铜皮傀儡：共通线热身战。生命 12，伤害循环 2、3、5；胜败都进入大雾。若此前把温脉符交给纪清寒，她会在战前将炼入剑意的符还给你，使生命上限 +4，但不恢复当前生命。
7. `fog` 大雾迷踪：根据最高人格显示锁线行动，进入四条独立路线。

血刃蛊令基础攻击伤害翻倍；血甲蛊替换甲衣蛊并免疫当前回合全部伤害。二者是血傀儡战的重要前置强化。

## 四、赵黎线：力量最终吃掉追逐力量的人

### 第三幕

1. `zhaoTrail`：你主动追上赵黎，形成只以机缘和实力维系的同行。
2. `zhaoLesson`：赵黎演示邪道炼血术；你固定取得“冰寒蛊简”。
3. `zhaoPrice`【对话二选一】：薛逢被机关困住，你与赵黎均不回头。你可以直说自己只救还有用的人，也可以暗中记下薛逢的位置，把他掌握的乔家路线当作尚未榨尽的价值。
4. `zhaoThreshold`：两人约定开门前联手，血魔蛊现世后各凭本事。

### 第四幕

1. `zhaoBloodGate`：乔无咎揭示血祭，你与赵黎只关注五转蛊茧。
2. `zhaoBloodGuard`【战斗】：独自证明取蛊资格；战败进入“命丧守墓傀儡”。
3. `zhaoAwakening`【对话二选一】：赵黎以血瓶唤醒血魔蛊，终止临时同盟。你可以追问他是否从未打算让你活着，也可以承认自己一直在等这场决斗；两种回应都会进入 `zhaoDuel`。
4. `zhaoDuel`【战斗】：与拥有反弹血幕的赵黎决战；战败进入“血蛊反噬”。
5. `zhaoClaim`：击败赵黎并固定炼化血魔蛊，替换原攻击蛊。
6. `zhaoQiaoDuel`【战斗】：以血魔蛊对决乔无咎；战败进入“命丧执棋者”。

### 第五幕

`zhaoFall` 描写血魔蛊反过来支配欲望；`zhaoEpilogue` 描写你杀尽墓中活人、踏着血水出墓，固定解锁“夺蛊成魔”。

## 五、纪清寒线：伸出的手要握到最后

### 第三幕

1. `jiTrail`：你救下纪清寒并固定接受包扎，生命上限 +4，当前生命不变。
2. `jiPromise`【对话二选一】：她入墓是为至亲寻找续命蛊材，却不愿把邪蛊带回世间。你可以劝她先顾好活人，也可以答应陪她找清最后的结果。
3. `jiBurden`：两人放弃捷径、折返救出苏莹，承担救人的代价。
4. `jiThreshold`：约定先救活人，再共同毁掉血魔蛊。

### 第四幕

1. `jiBloodGate`：进入祭殿后先救被牵机丝拖向血池的同行者。
2. `jiBloodGuard`【战斗】：纪清寒截住祭线，你迎战血傀儡；战败进入“命丧守墓傀儡”。
3. `jiRescue`：逐一斩断祭线，救回最后一名伤者。
4. `jiArrayTruth`【对话二选一】：循牵机丝确认乔无咎早已控制墓中机关。你可以让纪清寒留下守住伤者，也可以先与她约定两个人都要回来；无论怎样，她守祭殿，你独自杀入控制室。
5. `jiQiaoDuel`【战斗】：杀入控制室迎战乔无咎；战败进入“命丧执棋者”。
6. `jiDestroyGu`：两人固定自毁蛊种，在五转蛊完全苏醒前摧毁它。

### 第五幕

`jiAftermath` 带全部幸存者离墓；`jiEpilogue` 描写失去修为后的山野药铺生活，固定解锁“破蛊断脉”。

## 六、苏莹线：血脉不是命令

### 第三幕

1. `suTrail`【对话二选一】：沿雾中古文找到苏莹，确认她认识苏氏旧印。你可以直接追问她与苏氏的关系，也可以压下疑问，陪她看完阵盘古文。
2. `suInscription`：墓图显示墓主苏衍可能未死，旧玉与旧印回应。
3. `suLineage`：与她共同承受血脉禁制的反噬，固定记录“苏莹存活”和“苏氏血钥”。
4. `suThreshold`：苏莹决定亲自确认祖先留下的是传承还是罪孽。

### 第四幕

1. `suBloodGate`：绕过蛊茧，沿祖传铭文追查真正墓主。
2. `suBloodGuard`【战斗】：迎战只听命于棺中人的守墓血傀儡；战败进入对应死亡结局。
3. `suCoffin`：复原空棺遗文，得知苏衍要吞噬后人血脉恢复五转修为。
4. `suMasterTruth`【对话二选一】：苏衍命令苏莹献出血脉。你可以替她否认所谓苏氏旧债，也可以提醒她只需留下自己的名字；苏莹随后折断血钥，拒绝祖命。
5. `suMasterDuel`【战斗】：苏衍生命 28，兼具回血与吸血；战败进入“命丧墓主”。游方蛊医按设计无法获胜。
6. `suCollapse`：苏衍败亡，祖阵与血魔蛊崩塌，旧钥开启所有生门。

### 第五幕

`suAftermath` 让五名入墓者重新汇合；`suEpilogue` 让苏莹抛弃血钥、以自己的名字走出墓门，固定解锁“血脉归位”。

## 七、乔无咎叛徒线：看破棋局仍是棋子

### 第三幕

1. `traitorTrail`【对话二选一】：挟持薛逢，逼他替你避开机关并找到控制室。你可以折断他一根手指逼供，也可以许下一条根本未必兑现的生路。
2. `traitorKnife`：榨尽情报后冷酷灭口，夺走薛逢的牵机副印。
3. `traitorBargain`：接受乔无咎交易，成为取代薛逢的第二双手。
4. `traitorOath`：与乔无咎立下互不信任的短暂血誓，掌控部分机关。

### 第四幕

1. `traitorControlRoom`：从控制室俯瞰墓穴，成为第二位执棋者。
2. `traitorTrapJi`：以求救信号诱捕纪清寒，将其锁入献祭甬道。
3. `traitorSacrificeSu`：改写阵纹，把苏莹与血钥送入血祭。
4. `traitorQiaoTriumph`【对话二选一】：与乔无咎表面共享胜局。你可以称他一声家主、暂且低头，也可以掂量副印，提醒他胜负未定；双方都藏着反制手段。
5. `traitorZhaoArrives`：赵黎从控制图外的旧甬道出现，揭示两位执棋者漏算了局外强者。
6. `traitorBloodTaken`：赵黎撕碎认主阵、杀死乔无咎并夺蛊；你抛弃乔无咎逃跑。

### 第五幕

`traitorDiscarded` 揭示真正退路已随被你杀死的薛逢消失；`traitorDeath` 中赵黎以血光贯穿你的心脉，固定解锁“叛徒”。此线没有洗白或反杀赵黎的选择。

## 八、战斗、结局与维护规则

| 战斗 | 生命 | 失败结局 |
| --- | ---: | --- |
| 路线血傀儡 | 20 | 命丧守墓傀儡 |
| 赵黎 | 22 | 血蛊反噬 |
| 乔无咎 | 24 | 命丧执棋者 |
| 苏衍 | 28 | 命丧墓主 |

所有高潮战都在各自 `BattleConfig` 中显式填写 `defeatEnding`，不再由 `game.ts` 根据敌人名字猜测结局。主要固定结局为“夺蛊成魔”“破蛊断脉”“血脉归位”“叛徒”；“困于蛊墓”仅作异常或超时兜底。

每场战斗结束后，当前生命统一恢复至生命上限，胜败均执行这一结算。剧情选择和战前成长不再提供当前生命恢复；纪清寒归还的温脉符与她在个人线中的包扎只提高生命上限。游方蛊医的回春蛊、血魔蛊吸血等战斗内技能仍保留，因为它们属于回合策略而非场外恢复项。

- 四条路线的第三、四、五幕不得互相跳转，也不得重建公共高潮。
- `routes/contract.ts` 固定每线 4／6／2 个节点；修改结构必须同步更新合同和测试。
- 每条个人线固定保留两个二选一节点，一个在第三幕，一个在第四幕。两个选项必须拥有不同回应、相同 `next`，且不得附加 `effect`。
- 路线内选择只推进剧情与表达人格；除战败外，不得产生第二个主结局。
- 新战斗必须显式声明胜败去向和死亡结局，不得在 `game.ts` 按敌人名称硬编码。
- 当前存档版本为 6。旧版存档的共通线节点接线已经失效，必须拒绝读取。
