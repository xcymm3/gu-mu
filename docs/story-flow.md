# 《血蛊醒》剧情树

本文描述当前固定剧本的可玩结构。剧情与选项的唯一事实来源是 `lib/gu-tomb/game.ts`；本文用于快速查看路线，不替代代码中的条件与数值。

## 固定五幕合同

| 幕 | 名称 | 固定节点数 | 叙事职责 |
| --- | --- | ---: | --- |
| 第一幕 | 聚 | 1 | 墓门前集结，埋下旧玉、苏莹与生门的线索。 |
| 第二幕 | 入 | 6 | 五人连续入墓，建立猜忌、关系与真结局的三枚前置线索。 |
| 第三幕 | 离 | 4 | 大雾离散后与一人同行；四条内容不同的线路共享四个节点槽位。 |
| 第四幕 | 血流蛊室 | 3 | 四线汇合，揭露血祭，选择普通结局或真结局战。 |
| 第五幕 | 结局 | 不固定 | 由结局数据承载，不占用前四幕的节点合同。 |

## 四条同行线

### A：赵黎线

赵黎以远超四转的实力开路；你在枯骨蛊简中取得压制血流蛊的冰寒秘术。苏莹、纪清寒相继死去，赵黎将一切都当作分蛊者减少。终局中你借旧玉与冰寒秘术压住血流蛊，击败赵黎，独自成为血蛊魔君。

关键资源：`冰寒蛊简`。没有它，赵黎线的最终决战选项不会出现。

### B：纪清寒线

你们在陷道中互为后背。迷魂阵后的尴尬没有被挑明，却在一次次救援里变成信任。苏莹死于血祭，纪清寒愿以冰蚕剑冻结阵眼三息；你们选择毁蛊而非夺蛊，双双修为尽废，离开蛊墓后归于山野。

核心结局：`破蛊断脉`。

### C：薛逢线

薛逢始终谈散修互助，暗中却藏起乔无咎的活蛊线。你将计就计，以聚灵蛊反向留下追踪印记。终局中乔无咎把薛逢也列为祭品，你则借活蛊线截断控制室，夺得残缺血流蛊，成为亦正亦邪的血蛊枭雄。

关键资源：`活蛊线印记`。没有它，反制控制室的终局选项不会出现。

### D：苏莹线

苏莹的师门与苏衍有关，她知道“蛊不可祭，蛊只可承”，却不知如何终结血祭。正常情况下她会被傀儡刺死，你以身入血池，与血流蛊共生，成为血蛊主。

若在第一、二幕留下 `旧玉发烫`、`生门低语`、`活符低语` 三枚线索，旧玉会护住苏莹。它们分别对应旧玉的异常、纪清寒“墓在等人”的判断，以及苏莹认出活符；三者合在一起才足以让暗门回应。苏莹的血将开启暗门，苏衍诈死复苏，五人联手击败苏衍，进入真结局 `血脉归位`。

## 结局

| 结局 | 路线 | 核心条件 |
| --- | --- | --- |
| 夺蛊成魔 | 赵黎线 | 取得冰寒蛊简，并在节点 3 的赵黎决战中获胜。 |
| 破蛊断脉 | 纪清寒线 | 与纪清寒共同引爆祭阵。 |
| 血蛊枭雄 | 薛逢线 | 取得活蛊线印记，反制控制室。 |
| 以身饲蛊 | 苏莹线 | 苏莹死亡后，以自身与血流蛊共生。 |
| 血脉归位 | 苏莹线 | 三枚线索齐备、苏莹存活、击败苏衍。 |
| 命丧血池 | 任意 | 首领战败。 |
| 困于蛊墓 | 任意 | 时辰达到 4 且没有显式结局。 |
| 独活荒原 | 任意 | 未命中任何主要结局的兜底结果。 |
