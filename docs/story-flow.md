## 蛊斗与预告约定

蛊斗共 7 场：尸灯傀儡、血针机关、乔家血卫、血流邪修·赵黎、乔无咎、五转残魂·武意海、五转蛊修·武意海。

- 每场战斗以当前真元上限的满真元开始；真元归零时只能调息，恢复 3 真元。
- 非首领战胜利后恢复 2 生命；非首领战败会以 1 生命进入后续剧情。首领战不提供这项战后恢复。
- 敌人不显示生命数值，只有“健康／受伤／重伤”状态。
- 敌人行动不显示伤害数值或“威胁等级”；预告完全通过姿态、气息与环境变化表达。
  - 尸灯傀儡胸腹沉闷鼓动，表示它似乎要发动重击。
  - 血针机关从零星孔眼、两侧暗缝尽开到穹顶连绵机簧声，表现针势逐轮加重。
  - 赵黎血幕中的暗流倒涌，暗示来袭蛊术可能被反卷；取血瓶则暗示他试图借机恢复。
  - 武意海的蛊印、血雾与识海压迫，暗示攻击还会干扰真元。
- 当一击击杀敌人时，敌方不会再进行该回合的反击。

## 结局判定顺序

1. 全员生还 → **全员生还**
2. 叛徒末路 → **叛徒末路**
3. 武意海屠尽众人 → **血食**
4. 血流蛊化灰 → **破蛊出墓**
5. 乔无咎杀死你／赵黎夺走血流蛊 → **命丧蛊墓**
6. 时间 ≥ 4 → **困墓之人**
7. 已得血流蛊 → **夺蛊成魔**
8. 沈青萝未死、关系 ≥ 2、且持有沈砚玉牌 → **两人出墓**
9. 其余情况 → **独活荒原**

## 隐藏状态与资源

| 状态类别 | 来源 | 当前作用 |
|---|---|---|
| 人物关系 | 沈青萝、赵黎、贾贵、乔无咎的互动 | 不显示具体数值；会影响援手、赵黎放逐、青萝存活、真结局与部分战斗削弱 |
| 沈砚玉牌 | 井底空壳 | 与沈青萝关系共同满足“两人出墓”条件 |
| 血甲蛊 | 空血池 | 玩家取得时替换甲衣蛊为完全免伤；乔无咎取得时本体战生命 +4 |
| 血流蛊 | 赵黎战胜利／陆照野夺蛊 | 替换血刃蛊；对乔无咎战与“夺蛊成魔”结局至关重要 |
| 伤势 | 战斗、药物与丹药 | 决定后续战斗存活与赵黎战资格 |
| 真元上限 | 贾贵的护心膏、补元散 | 每次获得 +3；后续每场战斗以更新后的上限开战 |
| 时间 | 独行、井中选择、追乔无咎与战败 | 达到 4 时触发“困墓之人” |

1. `lib/gu-tomb/gu-tomb.ink.generated.ts` 或 `lib/gu-tomb/game.ts`：文本、选择与跳转；
2. `lib/gu-tomb/game.ts`：选择后果、战斗配置、行动预告与结局判定；
3. 本图：节点、数值、条件与结局连线；
4. `tests/game.test.ts`：至少覆盖新增分支的关键状态。
